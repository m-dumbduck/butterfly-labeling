# Обнаружение бабочек: данные и разметка

Датасет из **991 фотографии CC0** с проверенной разметкой взрослых чешуекрылых: **673 рамки, 506 положительных и 485 отрицательных кадров**.

Подготовка данных состоит из трёх стадий:

1. [Сбор и состав датасета](data/README.md) — источник, отбор, загрузка и формат данных.
2. [Разметка и независимое ревью](labeling/annotation.md) — Яндекс Задания, инструкции, интерфейсы, допуск и контроль качества.
3. [Итоговая проверка](labeling/validation.md) — агрегация, разбор ошибок, ручные исправления и проверка результата.

Изображения доступны по зафиксированным ссылкам iNaturalist. Итоговые рамки находятся в `data/annotations.jsonl`; исходные ответы, ревью и история исправлений — в `labeling/`. Основная оценка моделей проводится на всех 991 фотографиях. Категории источников и эталонные ответы не передаются модели на вход.
