# 1. Сбор и состав датасета

Фотографии собраны через API iNaturalist (`GET /v1/observations`, фильтры `photos=true` и `photo_license=cc0`). Лицензия проверялась для каждой фотографии. В манифесте сохранены идентификаторы, ссылки на изображения и наблюдения, сведения об авторстве и лицензии.

Выборка спроектирована для проверки обнаружения взрослых чешуекрылых: дневных и ночных бабочек, включая молей. В неё включены разные виды, места и даты наблюдений, одиночные особи, небольшие и перекрывающиеся объекты, скопления. Отрицательные примеры включают растения, других насекомых и незрелые стадии чешуекрылых. Таксон наблюдения использовался для поиска кандидатов, а не как готовая метка присутствия объекта.

Первоначальный набор из 600 фото расширен на 391 фото. При расширении дополнительно отбирались пчёлы, осы, жуки и растительность, чтобы лучше представить отрицательные сценарии. Из 400 кандидатов до разметки исключены восемь коллекционных экземпляров и один близкий дубликат. После разметки трудные кадры не исключались из итоговой оценки.

Выборка целевая, не случайная оценка распространённости бабочек в природе. Она содержит больше сложных случаев, чем типичная подборка крупных одиночных объектов. Итог: **991 фото, 506 с целевыми объектами и 485 без них**. Проверены открытие файлов, отсутствие точных дубликатов и пересечений по ID с отдельным экзаменационным набором.

## Файлы и загрузка

- `manifest.jsonl` — photo_id, URL оригинала, источник, размеры и SHA256.
- `annotations.jsonl` — итоговые рамки, одна запись на фотографию.
- `labels_with_provenance.json` — рамки с происхождением и историей решений.

Python 3.10+, дополнительных библиотек не требуется. Из корня репозитория:

```bash
python labeling/scripts/download_images.py
```

Изображения сохраняются в `data/images/`. Загрузчик проверяет SHA256; изменившийся или недоступный оригинал вызывает ошибку, а не подменяется другим изображением. Для проверки уже загруженного набора: `python labeling/scripts/download_images.py --verify-only`. Хранение по ссылкам зависит от доступности источника.

Рамка `{left, top, width, height}` нормирована на ширину и высоту приложенного изображения. Поле `shape` служебное. Пустой `boxes` означает отсутствие целевых объектов. Изображения не преобразовывались, их ориентация проверена.

Все 991 фото входят в основную оценку. Поле `legacy_use_for_model_eval` сохраняет прежний срез 934 краудсорсинговых фото; остальные 57 использовались как учебные и контрольные примеры для исполнителей, не для обучения моделей.
