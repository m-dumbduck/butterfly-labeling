# Материалы разметки

Описание процесса: [разметка и ревью](annotation.md), [итоговая проверка](validation.md).

- `configs/` — инструкции, интерфейсы, параметры пулов, обучения, экзаменов и контроля качества.
- `raw/` — исходные ответы обводки и ревью.
- `history/` — промежуточные версии, вердикты и объяснения исправлений.
- `reports/` — результаты проверки, расходы и пример ошибки.
- `scripts/` — три небольшие команды загрузки фото, агрегации ревью и сборки итоговых рамок.

Инструменты API и контроля качества находятся в корневой папке `tools/`; для загрузки датасета и офлайн-сборки они не требуются.
